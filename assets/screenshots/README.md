# MiniLMS UI Screenshots

This directory is designated for application interface screenshots and visual demonstration captures.

### Captured Workflows

1. **Dean / Executive Leadership Dashboard** (`dashboard_executive.png`): High-level KPI aggregations, retention rates, department grade averages.
2. **Academic Early Warning System (EWS)** (`early_warning_triage.png`): Automated 40/40/20 composite risk scoring, triage status, and intervention history.
3. **Teacher Grading & Rubric Assessment** (`grading_portal.png`): Continuous assessment, automated percentage recalculation, and letter grade assignment.
4. **Student Modular Learning Portal** (`student_modules.png`): Lesson sequencing, prerequisite locking, and completion timestamps.
5. **FERPA Privacy Directory** (`privacy_directory.png`): Data masking of student contact details for general directory queries.
